# Tableland test builds

Android test APK (not on Google Play yet).

**Download:** https://github.com/sirrenderstudios/tableland-builds/releases/latest/download/Tableland-test.apk

On your phone: open the link, download, then tap the file and allow "Install unknown apps" for your browser.
If you had an older Tableland test build, uninstall it first (this build is signed with a new key).
